# Olivia Aronson | Engineering Portfolio

Hi! I'm Olivia, a mechanical engineering student at the University of Tennessee at Chattanooga, minoring in psychology and particularly interested in biomedical engineering, assistive technology, and human-centered design.

This repository is home to my personal portfolio website, where I share engineering projects, technical work, and a few things about me that don't quite fit on a resume.

**[Visit my website!](https://oliviaaronson.github.io/)**

## A little about this project

I wanted a place to share my engineering work beyond a traditional resume. Somewhere I could explain the decisions behind my projects, show what I actually made, and have a little fun with the presentation.

What started as a portfolio also turned into an opportunity to learn web development!

I came into this with limited coding experience outside of my engineering coursework, so building the site has involved a lot of learning as I go. I've been getting more familiar with HTML, CSS, and JavaScript through experimenting, making changes, troubleshooting, and figuring out how the pieces work together.

I also used AI assistance throughout the process, particularly for generating initial code, working through unfamiliar concepts, and troubleshooting. It's been a useful way to explore web development while learning how to understand and modify the code myself.

I also added a few interactive features and mini games to make the site more fun to explore. They've been some of my favorite parts to experiment with while learning JavaScript!

## What's inside?

- **Engineering projects:** Design, fabrication, testing, and analysis from my mechanical engineering coursework.
- **Technical work:** Examples of data analysis, experimental testing, and technical writing.
- **A little personality:** Rock climbing, books, interactive games, and other things I wanted to share.

## Built with

HTML, CSS, JavaScript, GitHub Pages, and a healthy amount of trial and error.

## Main files

- `index.html` contains the main page content and links.
- `styles.css` handles the layout, colors, responsive design, and animations.
- `script.js` powers the interactive features and games.
- `resume.html` is the website version of my resume.
- `assets/` holds images and other media.
- `documents/` holds reports and downloadable work samples.

## Still a work in progress!

I'm continuing to update this site as I complete new projects, learn new skills, and find things worth adding. I also plan to keep improving the code as I become more comfortable with web development.
